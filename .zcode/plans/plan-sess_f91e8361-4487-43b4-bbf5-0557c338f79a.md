# 上下楼梯与识别跨障 实施方案（v3）

## 0. 思路评估结论

你的四步骨架全部保留（红色带复用、下沿直线拟合、旋转+横移对正、一步一拍闭环、爬楼方位微调），审查抓出的问题均已修正。核心测距机制为**机器人本地系地面单应**：`GroundHomography.from_pose(cam_xy=(0,0), cam_z=站立实测高, pitch=1000, head=1500)` 构造随机器人移动的单应（相机高度+俯角恒定时几何自相似，H 恒有效，已对照 nine_grid 现行用法与单测验证）——下沿点投影到本地地面系后直线拟合，一次得到（前向距离、方位角误差、横向偏移、内点率）。识别在原始像素、投影时逐点去畸变（GroundHomography 内置，不做全图 remap）。

**爬楼段方位闭环的几何依据**：站在台阶上（+2.5/+5cm）时，本地系单应以脚下平面为基准；横杆虽低于该平面 2.5~7.5cm，但该高度差对地面投影是**绕光心落地点的均匀径向缩放（×1.15~1.25），不改变直线方向**——方位角测量依然精确，仅距离读数有偏。故爬楼段**只用 bearing、不用 distance**。合成帧仿真须含此场景验证。

## 2. 感知与标定协议

- **标定**（一次 ~20 分钟）：红色目标 4~6 个按机器人本地系已知坐标摆放（卷尺量，**必须含横向偏移点**，否则偏航/横滚零偏不可观）→ `solve()` 全 H 最小二乘 → 自检（重投影 <20px、反推高度 25~55cm）。from_pose 仅作缺标定降级。
- **协议一致性**：标定与运行逐字同款——head=1500、pitch=1000、走后停 0.3s、同帧数策略；下楼后首次测量单点复验。
- **量化约束**：俯仰晃动 1° 在 30/45/60cm 处引入 1.1/1.6/2.3cm 距离误差 → 平地测量尽量压在 50cm 内；σ 实测值直接喂触发窗口公式。
- **同帧歧义**：接近楼梯段胶条与横杆可同帧可见（几何计算确认）→ 所有分量下沿点投地面系按前向距离聚类（间隙 5cm）→ 取最近簇，次近簇记日志。爬楼段直接选横杆簇（胶条在身后）。

## 3. FSM 与运动设计

```
INIT → ALIGN(不计时段) → APPROACH_STAIRS → CLIMB(含逐动作方位微调)
     → RECOVER → APPROACH_BAR → CROSS_BAR → EXIT → DONE
```

- **ALIGN**（入口光束前，不计时；穿光束自然发生在后续接近途中）：
  - 粗接近：递增步数 2→4→8 直到检出胶条（上限累计 ~100cm，超限停机报警）；
  - 细对正循环（≤8 轮）：拍 3 帧 → meter；|bearing_err|>tol_rot → turn_small ×⌈err/step_deg⌉（**turn_small 度数为现场第一优先实测项**，tol_rot=max(2.5°, 实测量子/2)）；|lateral|>tol_lat(3cm) → left/right_move ×1 → 每步视觉复核（打滑被下轮测量自吸收）；达标 → 前进至胶条距离=D_ALIGN(默认 40cm)。
- **APPROACH_STAIRS / APPROACH_BAR**（计时内，**一步一拍**）：每前进 1 步 → 停 0.3s → 单帧测量 + 最近 3 次滚动中位数；单次读数 ≤ 阈值 → **原地 3 帧突发复测**确认 → 触发下一阶段。d < d_min+6cm 自动切小步。窗口 = max(3cm, 步长+2σ)。D_CLIMB=d_min+3cm、D_HURDLE=d_min+4cm（横杆可见区内起跨，**无盲走段**）。
- **CLIMB（含逐动作方位微调，新增）**：动作组是阻塞原子，"实时"落地为**每个动作组执行完的间隙**测一次：
  ```
  for i in 1..2:
      climb_stairs → 小步 → 停稳
      拍帧 → meter(横杆簇) → |bearing_err| > TOL_ROT_CLIMB
            → turn_small ×⌈err/QUANTUM⌉（微调数值=TOL_ROT_CLIMB/QUANTUM，待现场标定）
  顶部：拍帧测 bearing → 实测转向修正（替代参考的固定 TOP_RIGHT_STEPS=2；
        横杆不可见时回退参考开环补偿值）
  for i in 1..2:
      down_floor → 停稳
      拍帧 → 同上方位检测与小步修正
  → stand
  ```
  爬楼段测量**只用 bearing**（距离受高度差偏差 ×1.15~1.25，不进任何触发逻辑）。几何确认：从台阶顶(+5cm)与一级(+2.5cm)看，横杆射线均越过台阶沿、位于帧中心附近，pitch=1000 可见。
- **RECOVER**（条件后退，不盲退）：stand → 拍一帧看横杆：可见且 ≥d_min+窗口 → 进 APPROACH_BAR；不可见 → 后退 1 小步再拍，迭代 ≤3 次。
- **CROSS_BAR**：hurdles 动作组（先试标准组，起跨距离不匹配则自制/调整，落脚点离杆留余量防 801S 误触发）→ stand。
- **EXIT**：前进现场标定步数出光束即停（宁少勿多，防冲进下一关入口）。
- **降级链**（不弃赛）：视觉丢失 → 变 pitch 至 950/1050（from_pose 同步重造，标注降级精度）重试 ×2 → 按步数航位推算 → 按推算位置重算步数的开环保底。CLIMB 段横杆不可见 → 回退参考开环补偿（TOP_RIGHT_STEPS 等）。拍照失败重试 ×3；FSM 整体 try 包裹，异常落 stand。
- **预算看门狗**（仿 nine_grid deadline）：单帧耗时实测值进场即得；预测超预算 → 一步一拍放大为 k 步一拍（k=2→3）、复测帧 3→1；**跨杆前那次测量不可砍**（碰杆 −2 > 超时 −1）。若实测步长 <1.2cm 且固件确为 80s → go_forward 连续走+stopActionGroup 预案（`机器人调用说明.md:60-66`）。

## 4. 非实机验证（M1/M2，全 PC 端，验收门）

- **几何精度扫描**（合成帧含真实畸变）：距离 15~70cm × 方位 ±25° × 横偏 ±15cm——距离误差 ≤1.5cm(≤50cm)/≤2.5cm(≤70cm)、方位 ≤1.5°、横偏 ≤1.5cm；叠加俯仰晃动 σ=0.5° 复测（阈值 ×1.5）。
- **爬楼方位场景**（新增）：相机在 +2.5/+5cm 平台、横杆低于脚下平面 2.5/5/7.5cm 的合成帧——bearing 误差 ≤1.5°（距离偏差仅验证不进触发）。
- **HSV 鲁棒性**：V±30%、色相向橙/粉边界偏移、阴影 → 单帧检出率 ≥95%。
- **FSM 端到端**：注入动作噪声（前进 ±15%、横移 ±20%、转向 N(2,1.5)°）→ 20/20 到达 DONE，跨杆起跨距离全部落窗，爬楼段航向终值收敛在容差内；降级路径（遮蔽胶条/横杆帧）验证不弃赛可达 DONE；拍照张数护栏作时间代理指标。
- 单测：几何正逆一致性（含高度差径向缩放的方向不变性）、检测器（合成帧）、FSM 决策表。

## 5. 实机里程碑

- **M1** 感知+几何+单测+精度扫描全绿（PC）
- **M2** FSM 端到端仿真 20/20（PC）
- **M3** 实机静态验证：三常数实测仪式（步长/单步耗时/单帧耗时）→ 全 H 标定 → verify_red_distance 达标（d≤50cm 误差 ≤2cm、σ≤1cm）→ **turn_small 度数 + TOL_ROT_CLIMB 微调标定**
- **M4** 分段实机：对正 → 接近 → 爬楼方位微调验证（逐动作间隙）→ 下楼 → 跨杆动作组匹配 → 出场，逐段验收
- **M5** 全流程联调 + 看门狗 + 时间预算达标

## 6. 风险与预案

| 风险 | 预案 |
|---|---|
| 爬楼段横杆不可见（光照/位姿） | 回退参考开环补偿值；降级链变 pitch 重试 |
| 单帧耗时长压缩 80s 预算 | 看门狗 k 步一拍自适应；连续走预案；与裁判确认固件阈值（80 vs 150s） |
| turn_small 量子过大 | tol_rot 自适应量子/2 |
| 胶条脱落/未贴 | 粗接近超限停机报警；开环参数表备用 |
| hurdles 动作组不匹配 D_HURDLE | 自制动作组（现场最大工作量，整段预留） |
| 楼梯开环参数随电量/场地漂移 | 参数表外置 + 标定表记录电量条件 |
| 分辨率若降档省时 | 须同步缩放内参并重标（默认不降 2592×1944） |
| MOTION_BUDGET_CM 无楼梯条目 | 补登记（仅影响日志；act() 只记不拦） |
