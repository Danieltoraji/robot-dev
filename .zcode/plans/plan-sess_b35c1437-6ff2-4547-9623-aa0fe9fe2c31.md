# 足球/球门检测：训练 + 树莓派5本地部署 实施方案

基线沿用已提交的《docs/视觉能力/足球与球门识别训练部署方案.md》（选型 YOLO nano 微调、云端训练、ONNX 导出、RPi 本地推理），按本次确认收敛：**目标硬件仅 RPi 5**（只导出 ONNX 640 一版，延迟 ≤1s，不做 416/int8 分支）；**本次只做训练+部署**，射门关卡（方案 §7）留下一轮，本轮仅保证 Detection 输出契约不变；数据**可实拍**。

---

## 阶段 A：采集与训练脚手架（仓库代码主体一）

1. **新增 `tools/data_collect/capture_dataset.py`**（机器人端批量采集脚本）
   - 沿用 fswebcam 决策（D2）：2592x1944 原图 + `-S 3` 稳曝光，存到 `/home/pi/dataset_raw/<场景前缀>/场景_序号.jpg`（不落 Pictures，与定位照片隔离）
   - 参数：`--scenes ball_near goal_front goal_light_bg negative ...`、`--count`、`--interval`，支持头部三档提示
2. **新增 `tools/train/` 训练脚手架**（容器云直接可用）
   - `datasets/football_goal/data.yaml` 模板：类别 `0: football, 1: goal`（沿用方案 §4.2，path 按容器内路径填）
   - `split_dataset.py`：按场景前缀划分 train/val/test ≈ 80/10/10，防止连拍同时进训练与验证
   - `train_baseline.sh`：`pip install ultralytics` + `yolo detect train model=yolo11n.pt epochs=200 imgsz=640 batch=32 patience=40`（yolo11n 为方案 §2.1 备选之一，与 yolov8n 同管线，改一行即可切换）
   - `export_onnx.sh`：`yolo export model=best.pt format=onnx imgsz=640`
   - `README.md`：容器云步骤 + 引用方案 §5.3 调优决策表
3. **新增采集规范一页纸**（`docs/视觉能力/足球球门数据采集规范.md`）：给现场拍摄人员的 checklist——覆盖矩阵（距离 0.3~3m、0.5~2m 加密；角度；头部三档；光照；白门浅背景/过曝难例；负样本 10~20%）+ 标注口径（football 框整球贴合边缘；goal 框门框+网体，底边中心=射门瞄准参考）+ 标注工具建议（X-AnyLabeling/LabelImg，输出 YOLO txt）

## 阶段 B：训练闭环（容器云，人工操作为主，脚本已备好）

4. 首批数据：每类约 200 张 + 负样本 → 标注 → split → 基线 100 epoch → `yolo detect val` 看每类 mAP50 与混淆矩阵
5. `tools/debug_vision.py yolo --model best.pt` 逐张可视化 badcase（现有工具直接用，无需改）→ 按决策表补拍（重点：白网+浅背景、网面过曝、球在门内/门前）
6. 正式训练 200 epoch + 早停。**达标线**：mAP50 ≥ 0.90（最低 0.85）、mAP50-95 ≥ 0.70、goal 在浅背景不系统性漏检
   - 可选提效：用 best.pt 对第二批原图预标注（伪标签），人工只做修正

## 阶段 C：ONNX 部署到 RPi 5（仓库代码主体二）

7. **`vision/yolo_detector.py` 新增 `OnnxYoloBackend`**：onnxruntime CPUExecutionProvider；letterbox 640 + 归一化；解析 YOLO ONNX 输出 (1, 4+nc, 8400) + NMS → 还原原图坐标 → `Detection`；与 LocalYoloBackend 同一 `detect(frame)` 协议，onnxruntime 懒加载
   - PC 单测：同一张图 ultralytics best.pt 与 ONNX 后端结果对齐（同类别、IoU>0.95）
8. **新建 `models/`**：`football_goal_yolo11n_640.onnx` + `models/README.md`（对应训练数据版本、val 指标、导出命令）
9. **新增 `tools/bench_yolo.py`**：对 20~50 张实拍图统计平均/最大单帧延迟，支持 `--image` 单张可视化；RPi 与 PC 通用
10. **RPi 5 实机部署验证**
    - 记录 RPi 端 Python 版本，`pip3 install onnxruntime`（aarch64 wheel，无需编译）
    - 按方案顺序：先 `LocalYoloBackend(.pt)` 跑通（ultralytics 已在代码中懒加载支持）→ 再切 ONNX 后端
    - 实拍验证：0.5~3m 检出、头部三档（中位/±40.5°/宽扫）、白门难例
    - **验收延迟：单帧推理 ≤ 1s**（fswebcam 拍照耗时不计）

## 阶段 D：收尾
