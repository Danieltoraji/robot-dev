# 足球/球门数据采集规范（现场一页纸）

> 依据：《足球与球门识别训练部署方案》§3。给现场拍摄与标注人员的操作清单。
> 采集工具：`tools/data_collect/capture_dataset.py`（机器人端，fswebcam 静态照 2592x1944）。

## 1. 拍摄命令

每个场景组合一条命令（场景名自定义，见 §3 命名建议）：

```bash
# 机器人上，项目根目录
python3 tools/data_collect/capture_dataset.py --scene goal_light_bg --count 15 --head left
```

- `--head` 取 `center / right / left / wide_right / wide_left`，**先手动把头部调到对应位置再跑**；
- 同一场景换机位/光照后用 `--start` 续拍（序号接着编号）；
- 照片输出到 `/home/pi/dataset_raw/<场景>/`，拍完整体拷回 PC 标注。

## 2. 覆盖矩阵 checklist（逐项打勾）

| 维度 | 要覆盖的组合 |
|------|--------------|
| 距离 | 0.3 / 0.5 / 1 / 1.5 / 2 / 3 m（**0.5~2m 射门关键区间加密**） |
| 角度 | 球门正面/左前/右前/侧面；足球各朝向、滚动姿态 |
| 头部 | 中位 / 左扫 / 右扫（宽扫各补少量） |
| 光照 | 室内灯 / 自然光 / 逆光 / 阴影 / 白网反光 |
| 背景 | 浅色墙 / 深色墙 / 地面 / 其它道具 / 空地 |
| 组合 | 球在球门附近、球门内、球门正前方、球被部分遮挡 |
| 负样本 | 无目标空场景，尤其是"像白网/圆形物"的干扰物（占总数 10%~20%） |

**白色铁网球门是头号难例**，以下组合必须单独拍够：

- [ ] 白网正对 / 斜对相机
- [ ] 网孔密集（近距）/ 稀疏（远距）
- [ ] 背景为白墙 / 浅色地面
- [ ] 球门部分出画（只露门框或网的一部分）
- [ ] 室内灯直射造成的网面过曝

## 3. 数量与命名

| 项 | 目标 |
|----|------|
| football / goal 各 | 300~600 张有效标注图（第一版可先每类 200 张快速验证管线） |
| 负样本 | 总数的 10%~20% |

场景命名建议（进目录名，供 `split_dataset.py` 按场景整体划分）：

```
ball_near / ball_far / ball_roll        # 球
goal_front / goal_left / goal_right     # 球门机位
goal_light_bg / goal_backlight          # 球门难例
ball_in_goal / ball_occluded            # 组合
negative                                # 负样本
```

## 4. 标注口径（全项目统一）

| 类别 | 类名 | 框法 |
|------|------|------|
| 足球 | `football`（id=0） | 框住整个球体，外接框贴合球边缘 |
| 球门 | `goal`（id=1） | 框住门框+网体整体；**框底边中心=射门瞄准参考** |

- 工具：X-AnyLabeling / LabelImg / Label Studio 任选，输出 **YOLO txt**
  （每行 `class x_center y_center w h`，归一化）；负样本不给 txt。
- 提效：第二批起可用上一版 best.pt 预标注（伪标签），人工只做修正。
- 疑难判定：球在门内时球与门**各自独立成框**，不许合并、不许漏标。

## 5. 拍完之后

```bash
# 划分（同一场景连拍整体进同一 split，防指标虚高）
python tools/train/split_dataset.py --src <标注目录> --dst datasets/football_goal
# 复制 tools/train/data_template.yaml 为 datasets/football_goal/data.yaml，改 path
# 上传容器云 -> tools/train/train_baseline.sh（步骤见 tools/train/README.md）
```
