# 视觉识别调试指南

> 配套：《视觉识别算法详解.md》（算法原理）、《视觉接入说明.md》（接入）。本指南讲「怎么把每个检测器调到能用在比赛里」。

---

## 1. 调试闭环（核心流程）

```
现场拍一张照片存盘
      │
      ▼
PC 上跑 tools/debug_vision.py 离线调参（反复，直到结果稳定）
      │
      ▼
把调好的阈值填回关卡的构造参数
      │
      ▼
实机验证；漂移了再回到第 2 步
```

> 离线调参不占用机器人、可复现，是首选方式。机器人上只需保留「拍照存盘」一步。

## 2. 工具

### 2.1 `tools/debug_vision.py` —— 一张图跑检测器并可视化

```bash
# 巡线·灰度（画中心线 + 分类 + lookahead，可 --out 存图）
python tools/debug_vision.py line --image photo.jpg --thresh 90 --roi 0.4 --out line.png

# 巡线·颜色（红色线，两段自动合并）
python tools/debug_vision.py line --image photo.jpg --hsv 0,120,80,10,255,255

# 颜色/球体（HSV 六元组：H_min,S_min,V_min,H_max,S_max,V_max）
python tools/debug_vision.py color --image photo.jpg --hsv 0,120,80,10,255,255 --label red_ball

# 数字（--templates 指向模板目录，缺省只标位置不识别）
python tools/debug_vision.py digit --image photo.jpg --templates templates/arial --thresh 90

# YOLO 本地（--model）或远程（--url）
python tools/debug_vision.py yolo --image photo.jpg --model yolov8n.pt --conf 0.5
python tools/debug_vision.py yolo --image photo.jpg --url http://192.168.1.10:5000/detect
```

不带 `--out` 时弹窗显示结果；带 `--out` 则保存标注图。

### 2.2 `tools/gen_digit_templates.py` —— 生成数字模板

```bash
# 用指定字体生成 0~9 模板（白字黑底），字号 40
python tools/gen_digit_templates.py --out templates/arial --font C:/Windows/Fonts/arialbd.ttf --size 40
```

建议生成**多套**（不同字体/字号），用 `debug_vision.py digit` 逐套试，选匹配分数最高的一套。

## 3. 各检测器调参

### 3.1 巡线 `LineDetector`

| 参数              | 作用                               | 怎么调                                                          |
| ----------------- | ---------------------------------- | --------------------------------------------------------------- |
| `hsv_range`       | 颜色模式目标色（给定即识别该色线） | 现场 HSV 取色；红给 (0,120,80)~(10,255,255)（红色两段自动合并） |
| `thresh`          | 灰度模式阈值                       | 先 `None`(OTSU)；仅灰度模式生效                                 |
| `roi_ratio`       | 只看画面底部比例                   | 0.3~0.5；看太远易受光照/弯道干扰                                |
| `min_area`        | 过滤小噪点                         | 大于噪点、小于最短有效线                                        |
| `lookahead_ratio` | 前视距离 L                         | 小=跟紧易震荡，大=平滑会切角                                    |

算法内常量（拐角/拟合，改 `vision/line_detector.py` 顶部）：

| 常量                                 | 作用                                  | 怎么调                                                 |
| ------------------------------------ | ------------------------------------- | ------------------------------------------------------ |
| `ELBOW_ANGLE_THRESH` (45°)           | corner 主判据：肘部弦角超过此值即拐角 | 调大更宽松（急弯才判拐角），调小更敏感（弧线也当拐角） |
| `ELBOW_WINDOW` (8)                   | 弦角滑窗半宽（像素）                  | 小=对局部折角敏感，大=更平滑抗噪                       |
| `ELBOW_MIN_NEAR_ARM_PX` (6)          | 近臂最小弧长                          | 过滤拐角脚下残留的短毛刺                               |
| `ELBOW_MIN_FAR_ARM_PX` (15)          | 远臂最小弧长                          | 过滤噪声毛刺造成的假拐角                               |
| `FIT_MAX_RMS` (4.0)                  | follow 拟合 RMS 上限                  | 超限改判 corner，防折线硬拟合成曲线                    |
| `FIT_MIN_POINTS` / `FIT_MIN_RY_SPAN` | 拟合最小点/跨度                       | 不足则直接量测不拟合（防 polyfit 病态）                |
| `LOOKAHEAD_CLAMP` (200)              | lookahead_x 钳制上限                  | 防多项式外推爆炸                                       |

**验收标准**：`debug_vision.py line` 画出的中心线点应落在线上；
`primary.orientation` 在直道为 `follow`、横线为 `cross`、直角弯为 `corner`；
`lookahead_x` 随线左右移动正确变化（拐角处改用 `lateral_offset`，`lookahead_x` 不可靠）；
`far_ry` 在线延伸至视野尽头时≈`roi_h`、线末端接近时显著变小（供终点判定）。

### 3.2 颜色/球体 `ColorBlobDetector`

| 参数                 | 作用         | 怎么调                                                          |
| -------------------- | ------------ | --------------------------------------------------------------- |
| `hsv_range`          | 目标颜色范围 | 用 HSV 拾取器取现场颜色，先宽后窄；左右阈值逐步收紧到只命中目标 |
| `min_area`           | 过滤小噪点   | 从画面里目标的最小面积往下留余量                                |
| 圆形度(`confidence`) | 是否「像球」 | 关卡里设 `confidence > 0.7` 左右；方块≈0.78，圆≈1.0             |

**验收标准**：只框出目标球，背景/地面不误报。

### 3.3 数字 `DigitRecognizer`

| 参数        | 作用     | 怎么调                                                     |
| ----------- | -------- | ---------------------------------------------------------- |
| `templates` | 数字模板 | 用 `gen_digit_templates.py` 生成多套，选匹配分数最高的一套 |
| `thresh`    | 分割阈值 | 先 `None`（OTSU），看数字是否被完整切成独立连通域          |
| `min_area`  | 过滤噪点 | 大于噪点、小于最小数字面积                                 |

**验收标准**：`digits` 输出与图中数字一致，`confidence` 稳定 > 0.5。

### 3.4 YOLO 本地 `LocalYoloBackend`

| 参数         | 作用       | 怎么调                                    |
| ------------ | ---------- | ----------------------------------------- |
| `model_path` | 模型权重   | RPi 上优先用 `n`/`s` 小模型或转 onnx/int8 |
| `conf`       | 置信度阈值 | 调高减少误报，调低减少漏检                |
| `iou`        | NMS 阈值   | 目标密集重叠时调小                        |

### 3.5 YOLO 远程 `RemoteYoloBackend`

先确认服务端可用（协议：POST 原始 JPEG，`Content-Type: image/jpeg`）：

```bash
curl -X POST --data-binary @photo.jpg -H "Content-Type: image/jpeg" http://192.168.1.10:5000/detect
```

算力端（KV260/PC）参考服务：

```python
# server.py（算力端）
from flask import Flask, request, jsonify
import numpy as np, cv2
from ultralytics import YOLO
model = YOLO("yolov8n.pt")
app = Flask(__name__)

@app.route("/detect", methods=["POST"])
def detect():
    img = cv2.imdecode(np.frombuffer(request.get_data(), np.uint8), cv2.IMREAD_COLOR)
    dets = []
    for r in model.predict(img, conf=0.25, verbose=False):
        for b in r.boxes:
            x1, y1, x2, y2 = [float(v) for v in b.xyxy[0]]
            dets.append({"cls": r.names[int(b.cls[0])],
                         "confidence": float(b.conf[0]),
                         "bbox": [x1, y1, x2 - x1, y2 - y1]})
    return jsonify({"detections": dets})

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```

## 3.6 视觉调试三工具分工（2026-09-07 新增）

| 工具 | 运行位置 | 相机 | 适用时机 |
|------|---------|------|---------|
| `tools/camera_preview.py` | 机器人 | **独占** `/dev/video0`（cv2 直连） | 机器人**空闲**时看实时直播（闯关运行时禁用——会抢相机致 fswebcam 静默失败） |
| `tools/debug_server.py` | 机器人 | **不碰**（只监视落盘照片） | **闯关运行中**：浏览器被动镜像机器人视角 + 检测结果叠加 |
| `tools/yolo_inspect.py` | PC | 不涉及 | **离线验证模型本身**：任意图片文件夹逐张看框/置信度 |

**debug_server 用法**（闯关运行前在机器人上启动一次，根目录一条命令）：

```bash
bash debug.sh          # 启动（自动杀旧实例、打印带 IP 的网址）
bash debug.sh stop     # 停止
bash debug.sh status   # 运行状态
bash debug.sh log      # 最近日志
# 底层等价: nohup /home/pi/jupyter-env/bin/python3 tools/debug_server.py --port 8081 &
```

- 原理：独立进程监视 `/home/pi/Pictures/photo_*.jpg`（关卡正常拍照的落盘处），
  新照片按开关重分析（tag+PnP 定位 / yolo / digit），HTTP 提供
  `/photo`（最新照片，960px 降采样 ~150KB）与 `/api/state`（结果 JSON），
  浏览器 1Hz 轮询 + canvas 叠加；
- 网页两组勾选框：**分析器开关**（控制机器人端是否跑该项分析，省算力）与
  **图层显示**（tag 角点/id/定位文本/yolo 框/conf/digit，纯前端）；
- **📷 触发拍照按钮**：关卡未运行时点一下，机器人立刻拍一张并自动出现在页面
  （不占摄像头的"手动拍照"入口）；**闯关运行时勿点**——会与关卡抢相机；
- 性能：每张新照片分析 <0.5s（拍照间隔 2~5s），独立进程与闯关无 GIL 争抢；
  未启动 = 零分析；分析只在机器人端，PC 仅绘制；
- 完整性保护：跳过损坏/半写文件（JPEG 尾标记校验），损坏的最新照片不会阻塞。

**机器人换网络/IP 变了怎么办**（DHCP 动态 IP）：

```powershell
python tools\set_robot_host.py http://192.168.新IP:8888   # 持久写入，sync/exec/pull 三工具共用
```

**yolo_inspect 用法**：`python tools/yolo_inspect.py --dir <图片文件夹>`，
`D/A` 翻图、`S` 保存标注图、trackbar 调 conf 阈值。

## 4. 常见问题（FAQ）

| 现象                       | 可能原因                                                            | 处理                                                                                  |
| -------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 线检测不出                 | 阈值/roi 不当、光照差                                               | 用 debug 看二值图；调 `thresh`/`roi_ratio`                                            |
| 球体误报一堆               | HSV 范围太宽                                                        | 收紧 HSV；抬高 `min_area` 与圆形度门槛                                                |
| 数字识别差                 | 模板字体/字号不匹配                                                 | 换 `gen_digit_templates.py` 生成的多套模板                                            |
| 远程请求失败               | 服务未启动/网络不通                                                 | 先 `curl` 联调；确认 IP/端口/超时                                                     |
| 本地 YOLO 慢               | RPi 算力不足                                                        | 换小模型 / 量化 / 切远程后端                                                          |
| 转弯后对准左右反复横移     | 转弯欠转过大（heading>25°），线倾斜使 lateral 与 lookahead 符号相反 | 对齐阶段先转向拉正线（`_align_to_line` 已内置）；检查转弯接近深度 `CORNER_APPROACH_Y` |
| 走到线末端不停止、反复进退 | 无终点判定或 `far_ry` 阈值不当                                      | 调 `LINE_END_FAR_RY`（线末端接近判定）、`LINE_END_BLIND_MAX`（丢线后盲目前进）        |
| 拐角转早/转晚              | 转弯接近深度不当                                                    | 调 `CORNER_APPROACH_Y`（越大越贴近拐角再转）；`CORNER_APPROACH_MAX`（接近步数上限）   |
