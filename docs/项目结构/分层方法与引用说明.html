1. 分层总览与依赖图

项目由 4 个文件构成 4 层，依赖方向为 main → level → core、sim → level + core。 其中 core 是唯一「不依赖任何关卡」的层，其它层都依赖它。

入口层 核心层 关卡层 模拟层 import / 调用方向

关卡levels/goodluck.pycore.robot_core（RobotState、distance_point_to_rect、HEAD_CENTER）本关卡数据 + 算法

2. 运行时调用链与 override 机制

这是理解整个系统最关键的一点：算法（关卡层）只通过 state.xxx() 调用「身体接口」， 而 state 在真机上是 RobotState（core），在模拟器上是 SimRobotState（重写了 3 个 I/O 方法）。 由于 core 的 locate_with_retry() 内部是用 self.solve_pnp() / self.run_action() 调用， 当 self 是 SimRobotState 时，这些调用会自动命中模拟器的桩方法，无需 monkey-patch。

方法真机（RobotState）模拟器（SimRobotState）是否被 core 内部调用
run_actionAGC.runActionGroup() 跑 .d6a更新 SimState 位置/朝向 + 刷新可视化✅ locate_with_retry 中调用
solve_pnp拍照 + AprilTag + cv2.solvePnP直接返回真实状态 + 注入噪声✅ locate_with_scan 中调用
set_headctl.set_pwm_servo_pulse() 转舵机仅记录脉宽，不转舵机✅ locate_with_scan 中调用
为什么只有 3 个方法需要重写：core 里真正「触碰硬件」的入口只有 run_action（动作）、 solve_pnp（视觉）、set_head（舵机）。其余方法（locate_with_scan、locate_with_retry、 compensate_head_offset 等）都是纯逻辑，它们通过 self 间接调用上面三个，所以只需重写这三个即可完成仿真替换。

7. 跨层引用矩阵

从「调用方 → 被调用方」视角汇总跨层引用（✔ 表示存在该方向的 import / 调用）。

被引用方 ↓ / 调用方 →main.pycore/robot_core.pylevels/goodluck.pysim/goodluck_sim.py
core/robot_core.py✔ import RobotState（内部 self 调用）✔ import RobotState / distance_point_to_rect / HEAD_CENTER；✔ 调 state.locate_with_retry / run_action / set_head✔ import RobotState / HEAD_*；✔ 继承重写 3 方法
levels/goodluck.py✔ import + 调 run_level✘（core 不依赖关卡）（内部函数互调）✔ import gl + 调 run_level / tag_poses / WALLS / ROUTE / 动作常量
main.py——✘✘✘（未复用 LEVELS）
关键结论：core/robot_core.py 对关卡层零依赖（✔ 只在「被依赖」方向出现），说明 core 的方向正确； 但 sim/goodluck_sim.py 对关卡层有大量 gl.* 依赖，且未复用 main.py 的 LEVELS 注册表，是当前最大的跨层耦合点。

8. 一次导航的完整调用链

以「到达停靠点 1」为例，展示一次从入口到执行动作的完整调用链（真机路径，模拟器用 重写 标记分支）。

main main() → 构造 RobotState → 调 run_level(state)
▼
level run_level() → assert_corridor_clear() → state.run_action("stand") → state.set_head(HEAD_CENTER)
▼
level navigate_to_target(停靠点1) 主循环开始
▼
core state.locate_with_retry() → locate_with_scan() → set_head() + solve_pnp() sim 重写
▼
core solve_pnp() → capture_image() → detect_apriltag() → cv2.solvePnP()（真机）/ 直接返回 + 噪声（sim）
▼
level 读 state.current_position / current_orientation → 计算 pd / dist / od
▼
level 朝向差超阈值 → decide_rotation_action() → state.run_action("turn_left")
▼
level 位置差超阈值 → decide_panning_action()（内部 distance_to_walls() → distance_point_to_rect()core）→ state.run_action("go_forward_one_step")
▼
core / sim run_action() → AGC 跑 .d6a（真机）/ SimState.apply_forward() + viz.update()（sim）→ 回到循环顶部重新定位

要点：level 层从不直接调用 capture_image / detect_apriltag / solve_pnp， 而是统一走 state.locate_with_retry() 这个「定位入口」；动作则统一走 state.run_action()。 这两个入口 + state.set_head() 就是 core 暴露给关卡的全部「身体接口」，也是模拟器唯一需要重写的 3 个点。
