## 1. 执行顺序（现场 runbook）

机器人在**机器人仓库根目录**执行，解释器必须用 venv：

```bash
cd /home/pi/Robot_Competition
PY=/home/pi/jupyter-env/bin/python3
```

### 测量 1 · 动作步长（≈20 min，唯一需要下发动作的测量）

> ℹ️ **阶段 0.1 对焦验证已改为自动化、不需要场地**：用
> `_tmp_tools/_tmp_focus_probe.py` 在多个候选焦距上比较拉普拉斯方差，
> 自动给建议值（脚本结束会**恢复探测前的原值**）。只要机器人在桌面上能
> 拍到任何有纹理的画面即可。执行结果见 §5 校验记录。

```bash
# 先干跑确认序列（默认就是干跑，不加 --run 不下发动作）
$PY tools/_tmp_measure_motion.py --group 1a --check
# 真跑：每组结束后停下等你用卷尺量总位移并输入
$PY tools/_tmp_measure_motion.py --group 1a --run      # 前进 ×20 ×3 组
$PY tools/_tmp_measure_motion.py --group 1b --run      # 左移 ×10 ×3 组
$PY tools/_tmp_measure_motion.py --group 1c --run --dir left    # 小转 ×20 ×2 组
$PY tools/_tmp_measure_motion.py --group 1c --run --dir right
```

每组重复前：**把机器人搬回原点标记、重贴方向线**。
产出：`archive/result/m1_motion.json`（均值 / ±3σ / **组间极差**）。
