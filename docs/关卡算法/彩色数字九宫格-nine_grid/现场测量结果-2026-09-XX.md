机器人在**机器人仓库根目录**执行，解释器必须用 venv：

```bash
cd /home/pi/Robot_Competition
PY=/home/pi/jupyter-env/bin/python3
```

> **`bash debug.sh` 不是 `sh debug.sh`** —— 脚本是 bash 语法，`sh`（dash）会在
> `set -u` 上报 `Illegal option` 并连锁报 `cd: $'.\r'` 之类的假错。
> 该镜像服务**不占用摄像头**（详见 §5 校验记录），测量期间开着无妨，
> 只要别点网页上的拍照按钮。
