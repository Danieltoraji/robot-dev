## 1. 目标与成功条件

**任务**：1m×1m 九宫格（3×3，左下格 6 恒空），7 块数字面板随机布局；
机器人按 **1→2→…→7 顺序**让承压部件通过各格心的**微动开关**；场地 ESP32 计分，限时 15 分钟。

**成功条件的形式化**：

> 对每一格 d，存在一个时刻，承压部件与格心开关的**横向偏差**在触发窗口 `t` 之内，且接触持续
> **≥0.5s**（电平扫描的可靠捕获时间，见 §2.2）。

**由此得到两条设计指令**：

1. **横向是主战场**。开关是 `6×6×5mm` 器件，横向盖不住就不计分；而前向只要"走够远、跨过那条线"——
   多走 3cm 不影响计分。**精度预算必须按方向拆开，横向是主项，前向是布尔裕量。**
2. **必须拿到厘米数**。判据若是"像不像到了"（画面份额、颜色事件），误差就是标定误差的函数；
   只有把"还差几厘米"直接解出来，横向闭环才成立。

**为什么不能靠"顺序断了就完蛋"来收紧策略**（固件事实，读 `NineGrid_ScoreSystem.ino` 得到）：
顺序错误**不清零、不锁死、只不计分**（`:247-251`），游标不动但**以后补上仍然计分**。
⇒ 误碰别的格**无害**（只吃该格 2s 冷却），卡住时可以先离开换视角再回头补。

## 2. 不可观测量的处理

机器人侧**没有任何开关回读路径**（无 GPIO 回线、无串口连接）。这一约束不变，但它不等于"盲跑"。

### 2.1 外部真值通道（零固件改动，可用）

| 通道 | 内容 | 用途 |
| :--- | :--- | :--- |
| **串口 115200** | **任何一次被接受的闭合都打印一行**：`📌卡槽N(位置M)→面板K`、`✅面板k! +10.0分`、`⚠️重复面板k`、`❌顺序错误！期望N,实际M`、`⏳非计分面板` | **"没有这一行"＝"开关没闭合"** ⇒ 逐格、甚至逐次接触的真值 |
| **OLED** | `Score` / `Progress: 1→2→[3]→…`（待打目标带方括号）/ `Time` | 现场最快的人工读数，手机拍一张即可复盘 |

⇒ **实验判定四分类**（缺一不可，否则"没加分"不可解释）：

| 现象 | 含义 | 处置 |
| :--- | :--- | :--- |
| `✅ 面板k! +10.0分` | 压到了且顺序对 | 正样本 |
| `⚠️ 重复面板k` | **压到了**，但处于该格 2s 冷却内 | 作废重做（不是负样本！） |
| 两者都没有 | 没压到（或闭合被 OLED 盲窗漏掉） | 负样本 |
| `❌ 顺序错误！期望N,实际M` | 压到了别的格 | 记 M，不计入本格统计 |

### 2.2 由此确定的两条时序事实

- **触发是电平扫描**（`:154-175`，主循环 `delay(10)`），`DEBOUNCE_TIME=200` 是**重复屏蔽**，不是"必须按住"。
- **但 `updateDisplay()` 每秒一次 ~1KB I2C 突发**（`:79-115`、`:506-509`）会造出约 **0.1s/秒的盲窗** ⇒
  **可靠接触取 ≥0.5s**。
- ★ **关键推论**：电平触发 ⇒ **停在格心上不动，开关就一直闭着**，
  与"滚过去"对计分器**完全等价** ⇒ 末端不需要"蹭"的巧劲，**停住即可**。
- **每格 2s 冷却**（`TRIGGER_COOLDOWN=2000`，`:68`），且**冷却在顺序判断之前更新**（`:182-186`）⇒
  同格想再压一次必须间隔 >2s。

## 3. 理论背景：一块已知边长的面板能给出什么

### 3.1 单目位姿：平面目标自带尺度

面板色块是**边长 L 已知的正方形**，四角共面。相机内参与畸变已知
（`core/camera_config`：fx 1944.904 / fy 1950.095 / cx 1283.069 / cy 983.198，
k1 −0.384402 / k2 0.284682）。四角像素（去畸变后）与已知边长 ⇒
`cv2.solvePnP(..., SOLVEPNP_IPPE)` 给出面板相对相机的 `(R, t)`。

**尺度来自 L，不是来自相机高度。** 这是整条路线成立的根：`L` 是**外部真值输入**（必须先量准，§6.1）。

### 3.2 地面系必须由**被观测面板的法线**给出（本设计的核心定理）

设相机系为 OpenCV 约定（x 右、y 下、z 沿光轴），面板中心 `t`，面板法线

  `n̂ = R · [0,0,1]`（IPPE 输出的旋转矩阵第三列）

面板躺在地面上 ⇒ **这块面板的法线就是地面的法线**。取正交基
`f̂ = normalize(ẑ_img × n̂)`（地面前向）、`l̂ = normalize(n̂ × f̂)`（地面横向），则

  **d_fwd = t · f̂， d_lat = t · l̂， D⊥ = t · n̂**

**这三个量是旋转不变量，与相机离地高度 h、与相机真实俯角 τ 完全无关。**

受控数值实验（合成真值 + IPPE 反解）：

| 地面系定义方式 | 前向/横向/法向误差 | 对 h、τ 的敏感性 |
| :--- | :--- | :--- |
| **观测法线**（本设计采用） | **0.000cm（机器精度）** | **完全无关**（h 取 40/45/51/56/60 结果一字不变） |
| 名义俯角常数（仓库现行默认路径） | **−11 ~ −14cm** | **≈0.9cm / 度** |

> 🚨 **硬规则 R1**：地面系基向量**只能**由被观测面板的法线导出，
> **绝不**用脉宽/名义俯角常数（`CAM_PITCH_MOUNT_OFFSET_DEG` → 59.9°）做这个换算。
> 否则 L2 会带一个**十几厘米的系统偏置**，比现有路线 8.7cm 的中位落点还差，
> 而且**不会报错**——数值照常输出，只是系统性偏。
> **回归闸**：把 `CAM_PITCH_MOUNT_OFFSET_DEG` 改成任意值，`panel_pose()` 的输出必须一字不变。

### 3.3 精度：随机项不是瓶颈，系统项是

解析近似（ε = 角点像素误差，f ≈ 1945，L = 边长）：

  `Δd_fwd ≈ ε · d² / (f·L)`，  `Δd_lat ≈ ε · d / f`

蒙特卡洛（含畸变投影 + `undistortPoints` + IPPE，n=400，均值≈0 即无偏）：

| 距离 | ±2px：Δ前向 / Δ横向 | ±5px：Δ前向 / Δ横向 |
| --: | --: | --: |
| 30cm | 0.06 / 0.04 cm | 0.15 / 0.09 cm |
| 40cm | 0.09 / 0.04 cm | 0.23 / 0.10 cm |
| 60cm | 0.15 / 0.04 cm | 0.41 / 0.10 cm |

**⇒ 横向定位在 ±5px 噪声下也只有 0.1cm 量级。随机噪声不是问题。**

**真正的误差源（全部是系统项，必须逐项消灭）**：

| 来源 | 量级 | 处置 |
| :--- | :--- | :--- |
| **边长 L 假定错** | **≈3.57% / cm 边长**（40cm 处 ±1cm → ∓2.86cm） | §6.1 卷尺直测 |
| **地面系用名义俯角** | **−11~−14cm**（0.9cm/°） | 硬规则 R1 |
| **畸变模型失配** | 30cm +1.13、50cm +1.26、**80cm +3.73cm** | 保留并核对 k1/k2，**不许用无畸变模型** |
| 面板翘边/不共面 | 0.5°/2° → −0.45/−1.80cm | 质量门 + 平面性先验 |
| 交棒时刻本身模糊 | **±2.7~5.3cm**（≈±1~2 步） | §4.4 改用远边行 + 提前交棒 |
| 末端死推 | 8 步 ≈ **0.36cm**（系统 0.045cm/步） | 可接受；步长须确认标定表面 |

### 3.4 可见性与裁切

- 可见地面带（h=51、τ=59.9）= **3.18 ~ 77.50cm**。
- **四角齐全窗口 = 15.0 ~ 70.5cm**：<15cm 时近边两角出画幅下沿；**>70.5cm 时远边两角出上沿**。
- ⚠️ **口径统一**："面板中心距 15cm"与"可见地面带下沿 3.8cm"是**两个基准，差 14cm**，本文一律用**面板中心距**。
- `cv2.solvePnP(SOLVEPNP_IPPE)` **要求正好 4 点**：只剩 3 角时 **100% 抛 `cv2.error`**。

**裁切后的降级模型（必须实现，不能只写在纸上）**：
面板躺在地面上 ⇒ 位姿只有 **4 个自由度**（3 平移 + 1 个面内转角，法线由地面给出）。
**3 个角点 = 6 个观测约束 / 4 个未知数 ⇒ 超定、可解，且余下 2 个自由度做残差自检。**
（反面：拿 4 点普通单应去拟合 3 点会精确穿过，残差恒为 0，**没有任何自检能力**。）

## 4. 实现方法

### 4.1 感知链（每帧一次，产出厘米数）

```
帧（原生 2592×1944）
 → 光照归一化 + 工作帧缩放（1296 宽，复用 vision.nine_grid_detector 的链路）
 → 目标色掩膜 → 最大外轮廓
 → ★ 四边形质量门：4 顶点 ∧ 边界偏离 ≤3~4 工作px ∧ 面积比 ∈[0.97,1.05] ∧ 凸实性 ≥0.95
      （同色粘连/残缺色块必须在这里被拒，不能带进位姿解算）
 → ★ 回原生分辨率做局部亚像素精修（梯度/直线拟合；工作帧顶点带 ±2 原生px 量化）
 → 去畸变（undistortPoints）
 → cv2.solvePnP(SOLVEPNP_IPPE)  →  (R, t)
 → 地面系由 n̂ = R·[0,0,1] 给出（硬规则 R1）
 → 输出 (d_fwd, d_lat, ψ_面内转角) + 残差
```

**硬规则**：

| # | 规则 | 原因 |
| :--- | :--- | :--- |
| **R2** | **禁用 `SOLVEPNP_IPPE_SQUARE`**，只许 `SOLVEPNP_IPPE`；并加"**重投影误差 >5px 即丢弃**"硬门 | `IPPE_SQUARE` 要求严格角点顺序，顺序一变就静默跑飞（实测重投影误差 3822~21431px） |
| **R3** | 二义性（两支解）消解要三条同时：① `Z>0`；② `n̂` 与地面法线先验夹角 <20~25°；③ **与上一帧的解连续** | "面板在前方"不够：100cm 处两支间距 5.49cm；同相机真机记录过**双支间隔中位 25.6cm、落错支 1/4** ⇒ 落错支＝一次 25cm 级假度量 |
| **R4** | 角点精修必须在**原生分辨率、局部 ROI、亚像素** | 工作帧 1296 = 原生一半 ⇒ 顶点 ±2 原生px 量化，与亚厘米目标矛盾 |
| **R5** | **不许**用"重投影 RMS"当角点精度验收 | 用同一批拟合顶点自算＝自证式；`approxPolyDP(0.02·peri)` 的容差本身 ≈5.3px，就是"偏离中位 5.2px"的来源 |
| **R6** | 畸变必须处理，保留并核对 k1/k2 | 无畸变模型 ⇒ 80cm 处 +3.73cm；畸变还让面板边缘**弯曲**（30cm 处远边 ±24.9px） |
| **R7** | 记录并规避"某地面方向接近与像平面平行"的病态角 | 该处单个正方形的两支消失点退化，姿态极不稳定 |

**两条已被证伪的担心**（不必再投入）：① "贴纸边缘发白/发暗 ⇒ 掩膜四角系统性内缩"——
真机 209 条边上量得共模偏置仅 **+1.0 原生px**（40cm 处 0.05cm）；
② "所有面板共面"——114 个消失点拟合地平线，残差中位 **0.6px**，成立。

### 4.2 控制律：横向闭环 + 前向扫掠

**每帧一次决策，只下发一个原语**（不批量、不算好 N 步一起做——步长估计一错就转过头）：

| 条件 | 动作 | 说明 |
| :--- | :--- | :--- |
| `\|d_lat\| > lat_tol` | 横移一步（方向由 `d_lat` 符号定） | **主闭环**，目标 ≤1.5cm |
| `\|ψ\| > ψ_tol` | 小转一步（方向由 `ψ` 定） | 使面板正对，改善角点条件 |
| `d_fwd > 交棒距离` | 前进若干步（步数 `= f(d_fwd)`） | 下一步仍复测 |
| 目标不可见 | 按"最后看到它的一侧"逐步扫；解出位姿时直接用布局算该转多少 | 见 §4.5 |

**过冲由下一步反向吸收**——这是本设计的稳定性来源，不追求一次到位。

### 4.3 前向的语义：扫掠，不是定位

前向不追求停在格心。**只要跨过开关线**：

  `n = ceil((d_fwd + margin) / 2.652)`，`margin` 取 3~5cm

误差只影响"走多远"，不影响"压没压到"。而停在格心上不动（电平触发）天然满足 ≥0.5s 接触。

### 4.4 交棒：用"面板远边像素行"，并把交棒点提前

**不用"是否开始裁切"当交棒触发**——裁切检测本身有 ±1~2 步（±2.7~5.3cm）的模糊，
而那一刻恰恰是 4 点 IPPE 失效的时刻。

**改用远边像素行**：

- 远边在**裁切后仍然可见**（近边出下沿时远边还在）；
- 其测距灵敏度只有 **9:1 ~ 30:1 cm/px**（近距放大率远小于角点法）；
- 前提：h 与 τ 各标定一次后**冻结**，并做一次零位校正（以"面板近边恰在画面下沿那一行"为参考零位）。

**并把交棒点提前到 25~30cm**：多付 2~3 步死推（0.1~0.15cm），
换回一帧"四角齐全、远边未贴画幅边"的高质量输入。

### 4.5 每格流程

```
进入本格 d（顺序计分；本格不确认就一直磨本格）
├─① 捕获目标：把头/身体转到目标入画（复用"头部四档扫 + 侧向记忆逐步转 + 每步复测"）
│     若能用布局表 + 自身位姿直接算出该转多少 → 直接用（省掉硬扫）
├─② 度量伺服：每帧 (d_fwd, d_lat, ψ) → 一次一个原语（§4.2）
├─③ 交棒（d_fwd ≤ 25~30cm 或远边行达到零位）→ 末端 n 步（§4.3）
├─④ 停住不动 ≥0.5s（电平触发 ⇒ 开关持续闭合）
├─⑤ 留档：度量估计的落点偏差(cm) + 串口/OLED 原文
│     ★ 日志里**不许**出现无条件的"到达 ✓"——那是自我安慰
```

### 4.6 已知布局的使用及其边界

场地计分器**本来就要求人工把布局串口输进去**（`readLayoutFromSerial()`，格式＝按槽位序给出
8 个面板号，例 `6,5,4,3,2,1,7,8`，第 8 个是占位槽）。同一份信息可以交给机器人：

- **单面板即可测距**（§3.1）⇒ 看到一块就知道"它离我多远、在哪边"；
- **两面板 + 距离** ⇒ 解自身位姿唯一（数值核实：只用方位角时"沿列进入"这种共线几何下
  场地内 **50 个解、最大差 29cm**；**加上距离后 2~7 个解、全部落在 1cm 内**）；
- **只有方位角时**，**必须 ≥3 块不共线面板**，否则**诚实弃权**，不许用欠定解决策。

⚠️ **规则边界**：说明书要求机器人"必须通过视觉识别数字和颜色判断当前位置，无法依赖固定路径记忆"，
面板可拆卸也正是为杜绝"死记硬背"。因此布局表**只作搜索先验与格号核验**，
**不替代视觉识别布局**；直接喂布局是否合规需用户/裁判裁决。

## 6. 验收判据（必须"非自证"）

| 对象 | 判据 | 为什么不是自证 |
