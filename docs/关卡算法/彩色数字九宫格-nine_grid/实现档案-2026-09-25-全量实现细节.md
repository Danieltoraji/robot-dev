## §5 默认控制流逐段（三段式，发货路径）

### 5.1 开局（`run_level`）

1. `deadline = now + 780s`
2. `lock_camera_controls()`（白平衡/曝光/对焦，失败不影响继续）
3. `auto_calibrate_exposure(state)`（把画面均亮拉到 `CAM_TARGET_MEAN=150`；换灯不必改常数）
4. `layout_scan()`：**失败即抛 RuntimeError**（整关白丢）
5. `for k in 1..7`：`go_to_panel(k)` → `state.act("stand")` → 打印 `[进度]`/`[遥测]`/`[遥测]判定依据`；熔断则记 `cell_trips`；`_abort_level` 或超 780s 则 break
6. 汇总 `[诊断] 中途终止的面板`、`[诊断] 各阶段拍照张数`

### 5.2 布局扫（`layout_scan`，最多 3 轮）

- 每轮：`for pitch in (1200, 1040): for pulse in (中位,左,右,宽左,宽右)` 拍帧 → `detector.detect_panels(arbitrate=True, drop_border=False, shape=True)`
- 提前退出条件（**两条同时成立**）：未裁切观测覆盖 ≥6 个数字 **且** 两档俯仰都已有观测
- 恢复 `head=HEAD_CENTER, pitch=PITCH_NAV`
- 缺数字则跳过拟合；否则收集颜色歧义表 → `_lattice_grid_fit` → 打印警告
- `_pose_bootstrap` 成功 → 写 `digit_cell` / `_pitch_offset_deg` / `_cam_height_cm` → 回填仲裁冲突格 → 打印标定结果 → return
- 失败：`_act("go_forward_one_step",1)` 前进一步重扫；3 轮仍失败 → `RuntimeError`
- **每格开始时会调 `sim` 的 `set_deform_digit(digit)`**（getattr 兜底，真机无影响）

### 5.3 逐格三段式（`_go_to_panel_v3` → `_seek_align_approach` / `_arrive_visual`）

**SEARCH**（`_search_target`，上限 4 轮 / 26 帧）：头部五档扫（低头档只在整轮失败后补 1 帧）→ 按 `_search_hint` 一次转 1~5 个大转步（22~129°）→ 若按死推纵向 >25cm 则盲走（单轮 ≤10 步 / 累计 ≤60cm）。提示 <5° 时固定左转。

**ALIGN**（`_align_visual`，上限 6 次迭代）：
- 每次 `_see_target_any`（中位找不到→五档扫）→ 得 `(obs,frame,yaw,box)`
- 方向自检：连续 2 次"同号误差被转得更大"→ 翻转 `_align_sign`（整局保持）
- 打转判据：连续 4 次转向后 |yaw| 未改善 → 走 `_align_ladder_step`（① 弃用小转 ② 放弃对准 ③ 熔断）；`no_rot` 时改为累计 `_tail_rot_blocked`
- 左右摆判据：死区外符号翻转 >3 次 → 升级阶梯
- 判档 `_zone_of_h(yaw, off_cm, near, px, py, w, h)`：
  - `VIS_ZONE_ENABLED=False` ⇒ 退化为 `|yaw| ≤ 12° → move 否则 rot`（**默认就是这条二值律**）
  - `move` ⇒ 返回 `(obs, frame, box)`
  - `lat` ⇒ 横移 1 步（`left_move`/`right_move`），更新 `prev_yaw`
  - `rot` ⇒ `|yaw|>30° 且未振荡` 走 `_big_turn`；否则小转闭环 `n = clip(floor(|yaw| / max(EMA, 0.8)), 1, 6)`
- 目标丢失且上一动作是转向 ⇒ 反向回退一半步数再试

**APPROACH**（`_approach_visual`，上限 60 次）：框宽 ≥920px 交棒（记 `_cell_handoff_yaw`）；框宽不涨连续 2 次 → 后退一步；步数 `box<0.6·920 → 5`、`<0.85·920 → 3`、否则 1。

**ARRIVE**（`_arrive_visual`，上限 30 次或预算不足时 ×0.6）：切低头档 1040；每帧
1. （可选）几何锚到达判据（默认关）
2. `detector.color_ratio(frame,color)` → 更新峰值峰值帧证据
3. 证据门素材：同色观测最大 hull → `ev_cover_now`、`ev_strip_now`（未裁切且 h/w<0.5）
4. `tail_accept = press ≥ 60×0.9 且 ratio < 0.80×peak`
5. 判据成立分支（`peak ≥ 0.02` 且（`ratio < 0.55×peak` 或 `tail_accept`））→ 再过两道门：
   - ① `peak_cover ≥ 0.08`（证据门，峰值帧面板占画幅）
   - ② `press_cm ≤ 70cm`（物理合理性）
   - 通过 → 记 `_arrive_evidence` 并 return True
6. 横移纠偏：`dx_cm = (px−W/2)/box·28`；`|dx_cm|>3cm` 且未超 4 次 → 横移 `clip(round(|dx|/2.2),1,3)` 步；擦边条观测跳过
7. 死推"到位即停压"：`|fwd|≤2cm 且 |lat|≤5cm` → `_note_dr_hit("stop")` 并 return True
8. 分段前压：占比还在涨 → 3 步（6cm），否则 1 步；`press_cm` 封顶 60cm
9. 循环用尽 → 死推兜底（≤6cm/≤5cm）→ 否则 False

**CONFIRM**（`_confirm_switch`）：后退 3.2cm + 前进 2.0cm 蹭步；冲突格近距复核；打印到达依据 + 距格心残差（>半格给警告）；并打印"微动开关状态在 Pi 侧不可读"。

**REANCHOR**（`_reanchor_pose`）：默认（非统一循环）**只把位置写到目标格心、航向保持死推值**。

## §8 布局扫与自标定

**数学原理**：可见面板 = 已知 3×3 刚性格阵（间距 33.33cm、格 6 恒空）经未知刚体变换后的带噪子集。

1. **假设-共识**：枚举"某对面板 = 相邻格"假设 → 其余面板在该格阵基下整数化 → 残差 ≤0.35 格距者为内点；**覆盖率门要求全部输入数字都是内点**；对角/跨格假设被共识自动否决
2. **4 个真旋转**（**不含镜像**，手性论证）→ 硬约束：无重复格 / 覆盖门（每板 ≤0.35 格距）/ 刚体残差门（干净子集 RMS ≤8cm）/ **入口侧谓词**（机器人必须在全部可见面板的入口侧）/ **列序谓词**（列 0 的 x 均值更小）；"格 6 恒空"优先但不硬杀
3. **排序**：`(not rule_ok, |cam_x − 50cm|, RMS)`；多解且居中度相近 → 判歧义（重扫）
4. **参数网格自标定**：`(offset 0~40° step 2.5°, h 36~70cm step 5cm)` 网格上逐组合做"机器人系映射+逐数字聚合+格阵拟合"，**多数票定布局**（需 ≥60% 且 ≥10 组合），胜出组合中位数即自标定常数
5. **像素域五参数精修**（`_pixel_pose_calib`）：解 `(x,y,θ,offset,h)`，用与导航同一残差定义 + Cauchy 鲁棒 + 弱先验；门用**中位残差** ≤40px（避开少数坏观测抬高 RMS）
6. **位姿自举**：优先用像素精修位姿；否则刚体拟合，自检残差/入口侧/场地范围

**聚合策略**（`_aggregate`）：同一数字的多次观测先按 6cm 邻域聚类**取最大一致簇**（防木框/地垫被阈值命中），簇内**干净（未裁切）优先**，否则用裁切并把权重降到 0.3。

**歧义修复**（`ambiguity_repair`）：只用无歧义且可信的数字拟合刚体变换 → 比较歧义数字的观测点到"本格"与"竞争格"预测位置的距离（需双向都近出一个余量 8cm）→ 交换后**残差必须下降**才接受。

## §9 定位与地图锚

- **GN 地图定位**（`localize`/`_gn_localize`/`_gn_run`）：地图 = 布局扫得到的 9 个格心；每步用名义动作模型预测位姿作先验；对应点残差 = 投影中心 ↔ 观测中心（裁切时用 `clipped_quad_centroid` 预测 ↔ `hull_centroid_px`）；IRLS(Cauchy c=4px) + 弱先验正则（σ=8cm/8°）；多起点（±8cm/±10°）；门控 RMS ≤12px、跳变 ≤12cm/30°；失败返回 None（**不改位姿**）。**依赖冻结的相机常数 ⇒ 地板形变下会整片超门控，这正是 v3 改视觉伺服的原因**。
- **MAP-ANCHOR**（`_map_anchor`）：把"地图说数字 d 在格 c"与"本帧看到 d 在像素 p"配对 → RANSAC 枚举 4 子集（上限 80）解 `GroundHomography` → 内点 ≥5 → 合理性守卫（反解高度 25~90cm、H 前两列模长差 ≤0.05、位姿不离场心 160cm）→ 输出实测位姿 + 反解相机高度。**不冻结任何相机常数 ⇒ 天然抗形变**。
- 裁切面板的**未裁切角点**作对应点把 ≥4 对应的帧占比从 14.7% 提到 **46.1%**。
- **实测可用率**：整关 ~5%（v1）/ ~15.8%（v2）；逐格可用数 `7,1,0,0,1,0,0`。⇒ 只能是"长距帧的核验/定位器"，不是全程机制。
- 默认 `MAP_ANCHOR_ENABLED=False`；`VIS_REANCHOR_BY_ANCHOR=True` 但被 `UNIFIED_NAV_ENABLED=False` 短路 ⇒ **默认路径上锚一次都不跑**。

## §11 容错、护栏与安全

| 机制 | 触发条件 | 后果 |
|---|---|---|
| 单格硬熔断（时间） | `now > min(now+min(70, 剩余/剩余格数×0.9), 软预算)`，下限 45s；**每次拍照/动作前判** | 本格记未确认，立即返回 |

| 单格硬熔断（动作） | `_cell_actions > 300` | 同上 |
| 转向预算 | 单格累计**命令**转角 >360° | **拒绝执行那次转向**并熔断本格 |
| 离场护栏 | 死推位姿出 `x∈(−33,133)/y∈(−48,133)` | 熔断本格 + **中止整局**（站立收手） |
| 全局看门狗 | `now > deadline(780s)` | break 出主循环，保住已得分 |
| 打转判据 | 连续 4 次转向 |yaw| 无改善 / 死区外左右摆 >3 次 | 三级阶梯：弃用小转 → 放弃对准 → 熔断 |
