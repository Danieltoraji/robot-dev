# 现场测量计划 — nine_grid（2026-09-15）

> 依据：`交接报告-2026-09-14.md` §6 + §2 硬约束 + §5.5 三处不确定。
> 原则：**全程不改关卡代码**。测量产出的数字决定后续所有阈值（FIXED_TAIL、证据门、横移增益、形变策略）。
> 协作分工建议：人负责摆面板/卷尺/搬机器人，AI 负责下发动作、采帧、拉回数据、离线分析。

---

## 0. 统一口径（先读，测量大忌是口径漂移）

| 项 | 约定 |
|---|---|
| 距离定义 | **面板中心 → 机器人原点标记的地面水平投影距离**（cm）。不用斜距。 |
| 原点标记 | 机器人上电摆放前，在地面贴"十"字标记（底盘中心投影），并贴一条前进方向线 |
| 面板摆法 | 面板平贴地面、数字朝上、垂直于前进方向；边缘对齐方向线（保证正对，不斜进） |
| 俯仰/头部 | 近距帧一律低头档 **PITCH_DOWN=1040 + HEAD_CENTER**；布局扫用 PITCH_NAV=1200 |
| 光照 | 每次开工先跑 `tools/field_probe_ninegrid.py`（锁白平衡 4000K/对焦 166 + 自动曝光标定）；中途换灯/换场地必须重锁 |
| 帧命名 | `m{测量号}_d{距离}cm_{重复号}.jpg`（如 `m2_d24cm_1.jpg`），文件名即数据 |
| 阈值适用性 | 现场同检测器占比峰值只有 0.059~0.072，**sim 的 0.118~0.187 不可搬**——所有门限以本次实测为准 |

## 0.5 开工前检查（约 10 分钟）

1. PC：`python tools/sync_to_robot.py --check` —— 确认 PC 与机器人代码一致（HEAD be30f81），**避免测到旧代码**。
2. 机器人上电、置于原点标记；跑一次 `field_probe_ninegrid.py` 确认锁定生效、颜色检出正常。
3. 器材：卷尺、美纹纸+笔（贴标记与编号）、量角器或手机水平仪（测转角用）。

## 测量 1 · 动作步长标定 【命门，约 20 分钟】

**决定**：`FORWARD_ONE_STEP_CM`（现写 2.0，实为 3~4）、`FIXED_TAIL` 收尾步数（草案 4.25~5.7 步）、横移修正系数（已知欠纠 ~14%）、`FIELD_SMALL_TURN_STEP_DEG`（现写 11.0，trace 实测 2.45°/步）。

**步骤**（用新脚本逐组执行，见 §2 脚本）：

| 组 | 动作 | 次数 | 量的量 | 重复 |
|---|---|---|---|---|
| 1a 前进 | `go_forward_one_step` | 20 步 | 沿方向线的前进位移（卷尺） | **3 组**（每组搬回原点重贴线） |
| 1b 横移 | `left_move` | 10 步 | 垂直方向线侧移 | 3 组 |
| 1c 小转 | `turn_left_small_step` | 20 步 | 总转角（地面延长线法：出发方向线 + 终了朝向线，量角器/手机测夹角） | 2 组，左转右转各 1 |

**记录表**（每组填一行，脚本自动算均值与 ±3σ）：

| 组 | n 步 | 实测 cm（或°） | 单步均值 | 
|---|---|---|---|
| 1a-1 | 20 | | |
| 1a-2 | 20 | | |
| 1a-3 | 20 | | |
| 1b-1~3 | 10 | | |
| 1c-1/2 | 20 | | |

**判读**：
- 前进单步均值进 `FIXED_TAIL` 公式：触发时中心距 17cm ÷ 实测步长 = 所需步数（向上取整后复核落点是否仍在 ±5.5cm 内）。
- **重点看重复性**：若组间极差 >1.5cm（步长 3 和 4 交替），说明"步长随地形/电量变"，S4 必须再加保守余量或改两段触发。

## 测量 2 · 近距几何剖面（面板正前 40→10cm，每 2cm，低头 1040）【约 15 分钟】

**决定**：S3 压入触发点、S4 盲区触发距离、证据门 `VIS_ARRIVE_EVIDENCE_MIN_COVER`（现 0.08 现场可能拒真面板）、"像宽当尺"标尺关系的现场有效性。

**步骤**：橙色面板正对机器人，从中心距 **40cm** 开始，每 **2cm** 逼近拍一帧低头帧，直到 **10cm**（共 16 帧）；整套重复 2 遍。帧名 `m2_d{距离}cm_{遍数}.jpg`。

**分析**（帧拉回 PC 离线跑真实检测器，现场不等结果），对每个距离记录：

| 记录项 | 物理含义 / 决定什么 |
|---|---|
| `clipped` 是否为真 | 首次为真的距离 = 视觉盲区起点（验证 15~17cm 推断 → 定 S4 触发） |
| bbox 可见高度 bh 序列 | 首次**连续**下降的距离 = S3 压入触发点（单调性验证 §5.3 的核心假设） |
| color_ratio 全屏 + 下半屏 | 峰值与曲线形状 → 重标证据门；验证"下半屏滤木框"在现场仍成立 |
| 像宽 boxW 序列 | 对照 `boxW ≈ fx×28/深度`（35cm 处约 44px/cm）；线性段 = "面板当尺"可用区间 |
| 木框/杂物干扰占比 | 每帧非面板同色像素（延续 09-14 的 12 帧分解） |

**判读**：
- 若 bh 单调下降段不存在（噪声大）→ S3 判据退回"占比峰值回落"并用现场峰值重标；
- 盲区起点若早于 17cm（遮挡先于几何出画）→ S4 触发改用遮挡足迹（见测量 4）。

## 测量 3 · 横偏增益（+5 / +10cm，约 5 分钟）

**决定**：横移纠偏增益系数（日志显示报 2.2 实际 1.9，欠纠 14%）。

**步骤**：面板中心距固定 **35cm**（正前对照 1 帧 + 左偏 5cm 1 帧 + 左偏 10cm 1 帧；可加右侧对称帧）。

**分析**：对每帧用检测器中心算 `(cx − W/2) / 像宽 × 28`，与卷尺真值横偏比对 → 增益 = 真值 / 估计。

---

## 测量 4 · 机体遮挡足迹（20 / 15 / 10cm，约 10 分钟）

**决定**：S3→S4 的判据选 `clipped` 还是"可见区第一行贴机体"；确认遮挡是否早于几何出画。

**步骤**：面板放正前 20/15/10cm 三档各拍 1 帧低头帧；量每帧"面板可见区第一行像素行号"（也可在 PC 上对帧做逐行色块分析）。**测量 2 的 16/14/12/10cm 帧可直接复用**，此测量只补缺失档位。

---

## 测量 5 · 真实形变幅度（约 15 分钟）

**决定**：形变场景策略（±5° 与 ±15° 对应完全不同的结论——**±15° 从未实测**）；GN 方案 I 的优先级。

**步骤**：机器人静置在 **3~4 个不同格位**（至少含最远格与最近格，模拟跨格后位姿），每个位置各跑一次 `tools/run_layout_scan.py --out m5_pos{N}.json`（不动底盘，自动输出自标定常数：有效俯角/高度）。

**判读**：
- 取各位置"有效俯角"的**跨格极差**：≤±5° → 形变可按小幅处理、阶跃场景降级；接近 ±15° → 保留阶跃场景策略，S1 对准必须保持"只看符号"。
- 顺带核对各位置自标定高度是否稳定（一局一冻是否合理，或必须支持中途重标 = GN 方案 I 的前置论据）。

## 收尾（约 10 分钟，PC 侧）

1. `python tools/pull_from_robot.py` 拉回全部帧与 JSON → `tests/fixtures/field_photos/`（建 `2026-09-XX_*/` 子目录）。
2. 离线复算：测量 2/3/4 全部分析在 PC 上用真实 `nine_grid_detector` 跑，输出一张汇总表。
3. 数据与结论归档 `docs/关卡算法/彩色数字九宫格-nine_grid/现场测量结果-2026-09-XX.md`，并据此刻画 S0-S5 全部阈值 → 提交用户过目 → 才进入改码阶段。

## 需新写的两个测量脚本（动手前需用户同意；均不触碰关卡代码）

| 脚本 | 功能 | 用完处置 |
|---|---|---|
| `tools/_tmp_measure_motion.py` | 交互式：执行某动作 N 次 → 暂停等人卷尺 → 输入实测值 → 全部组完成后打印均值/±3σ 汇总 | 用后删除或转正；命名带 `_tmp_` 保证 .gitignore 兜底 |
| `tools/_tmp_dist_sweep.py` | 按输入距离序列（如 `40..10,-2`）逐档：提示摆位 → 拍帧（1040 档）→ 按约定命名存盘 | 同上 |

安全与纪律：机器人只在原点标记附近小步移动，无失控风险；任何动作脚本先 `--dry` 打印动作序列再真跑；全程不经 `run_level`，不写 results，与计分无关。
