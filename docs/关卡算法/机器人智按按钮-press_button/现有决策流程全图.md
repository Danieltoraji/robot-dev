## 2. 观测：一次 = 恰好一张照片

`_observe(id)` :347 → 拍照失败或未检出返回 `(None,None)`；命中则给出两个标量：

| 量 | 来源 | 含义 |
|---|---|---|
| `cx` | `corners[:,0].mean()` :241 | 标签中心横向像素 |
| `w` | `corners[1][0]−corners[0][0]` :240 | 标签顶边 x 投影长度（非真实边长） |
| `seen` | 本帧全部检出 id :234 | **只作打印，控制逻辑不用** |

无帧间状态（不记上一步做了什么、也没有历史）。

## 3. 唯一判据 `decide()` :195-212（顺序即设计）

```
cx < 1215 (1296−81)  → turn_left    ×1（22.0°，计 _turns）
cx > 1377 (1296+81)  → turn_right   ×1（25.7°，计 _turns）
w  < 324             → go_forward   ×1（5.0cm，不计 _turns）
否则                  → press ×2 → back_fast ×6 → 头回中
```

## 4. 主循环 `_track_and_press()` :431-475（唯一闭环，无显式状态变量）

```
_reset_target_counters() :438（_turns/_search_rounds/_last_seen 清零）→ set_head(1500)
while True:
    cx, w = _observe(id)                :442   ★ 每轮先拍一张
    cx is None → _search_step()          :445   §5
    turn_left  → _turn(A_TURN_L,1)       :452
    turn_right → _turn(A_TURN_R,1)       :456
    forward    → _act(A_FWD,1)           :460
    press      → press×2 :467 → back_fast×6 :472 → 头回中 :473
                 results.append :474 → return True :475   ← 唯一出口，没有失败返回
```

**每个动作后都回到 while 顶部重新拍照** ⇒ 已经是"一步一闭环"，没有开环段；但循环里没有帧间状态，无法预判"直行会把航向带偏多少"（仓库在 goodluck 里为此单加了"转向后重新定位自纠"，`:263-267`）。

## 5. 搜索环 `_search_step()` :396-427（一轮 = 最多 3 张照片 + 最多 1 次身体转向）

```
左转头 1800 → 拍照，命中 → 头回中 + 身体左转 1 步
右转头 1200 → 拍照，命中 → 头回中 + 身体右转 1 步
头回中 → 身体左转 2 步（每轮净左转 44°）
```

命中时身体固定转"一步"，不看偏差大小。

## 6. 主流程与护栏

```
_task_flow() :479
  stand → 预置 turn_left×2 :487 → [任务1: id=102, stop_w=324] :489
        → 预置 turn_right×2 :494 → [任务2: id=101] :496
        → 收尾 turn_right×2 :501
  finally: set_head(1500) + stand :507
```

| 计数 | 上限 | 超限 |
|---|---|---|
| `_turns` 单目标转向 | 40（每目标清零；**预置转向也计入**） | 抛 `BudgetExceeded` |
| `_search_rounds` 单目标搜索轮 | 10 | 同上 |
| `captures` 全局拍照 | 400（不清零） | 同上 |

退出路径（`run_level` :540-551）：捕获 `BudgetExceeded` / `KeyboardInterrupt` / 其他异常 → 打印 → `_summary()` → 返回 bool。**`ok1=False` 时不重试任务1，直接做任务2。**

## 7. 重写必须正视的三件事

1. **观测只有 2 个标量且无帧间状态** ⇒ 隐含假设"转向只改 cx、前进只改 w"，而直行会同时改两者。
2. **判距离用 `w`** ⇒ 斜视时系统性偏乐观（侧偏 30cm 时 30cm 读成 60cm），见新版 §3。
3. **无失败出口**；且任务1失败不重试，与"顺序计分"规则冲突。
