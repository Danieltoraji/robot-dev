## 推荐阅读路径

- **新人上手**：`../readme.md` → `定位逻辑详解.md` → `分层方法与引用说明.html`
- **开发新关卡（视觉）**：`视觉识别算法详解.md` → `视觉接入说明.md` → `视觉调试指南.md`
- **维护 / 重构 core**：`架构分析报告.md` → `分层方法与引用说明.html`
- **想彻底理解定位**：`定位逻辑详解.md` → `introduction.md`

- `.html` 是生成的讲解文档，可能滞后于最新代码结构（如 `vision/` 加入后），**以 `.md` 与代码为准**。
- 各文档交叉引用以《书名号》形式给出，同目录下直接互链；跨目录用相对路径。
