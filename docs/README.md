# 文档导航（docs/）

本目录集中存放项目文档，按主题分 4 类，**各司其职**。

## 目录结构

```
docs/
├── README.md                         # 本文档：导航 + 各文档职责
├── 比赛相关材料/
│   ├── 机器人调用说明.md              # 硬件接口：动作组/舵机/摄像头（原始参考）
│   └── 各关卡说明/
│       └── goodluck关卡赛道说明.md     # goodluck 关卡规则与赛道坐标
├── 关卡算法/
│   ├── introduction.md               # goodluck 寻路算法设计文档（原始，见文首现状说明）
│   └── robot-dev_explanation.html    # 项目整体讲解（HTML 生成物）
├── 项目结构/
│   ├── 架构分析报告.md                # core/关卡职责边界审查（含修复记录）
│   └── 分层方法与引用说明.html         # 各层方法 + 引用关系（HTML 生成物）
└── 视觉能力/
    ├── 视觉识别能力规划.md            # 视觉能力：架构 / 决策 / 路线图
    ├── 视觉识别算法详解.md            # ★ 各检测器算法原理
    ├── 视觉接入说明.md                # 关卡如何调用检测器
    └── 视觉调试指南.md                # 调参 / 标定
```

## 各文档职责（各司其职）

| 文档 | 回答的问题 | 读者 |
|------|-----------|------|
| 视觉识别算法详解.md | 每个算法「怎么做」（原理 / 公式 / 流程） | 想搞懂算法的人 |
| 视觉接入说明.md | 关卡里「怎么用」（API / 示例） | 关卡开发者 |
| 视觉调试指南.md | 「怎么调到能比赛」（标定 / FAQ） | 现场调试 |
| 视觉识别能力规划.md | 「为什么这么做」（架构 / 决策 / 路线图） | 想了解来龙去脉 |
| 架构分析报告.md | core 与关卡「边界是否合理」（审查 + 修复记录） | 维护者 |
| 分层方法与引用说明.html | 各层「有哪些方法、谁调用谁」 | 维护者 / 重构 |
| introduction.md | goodluck「寻路算法原始设计」 | 理解定位 / 导航算法 |
| robot-dev_explanation.html | 项目「整体是什么」 | 新人上手 |
| 机器人调用说明.md / goodluck关卡赛道说明.md | 硬件接口 / 赛道规则 | 参考 |

## 推荐阅读路径

- **新人上手**：`robot-dev_explanation.html` → `分层方法与引用说明.html`
- **开发新关卡（视觉）**：`视觉识别算法详解.md` → `视觉接入说明.md` → `视觉调试指南.md`
- **维护 / 重构 core**：`架构分析报告.md` → `分层方法与引用说明.html`

## 说明

- 两个 `.html` 是生成的讲解文档，可能滞后于最新代码结构（如 `vision/` 加入后），**以 `.md` 与代码为准**。
- 各文档交叉引用以《书名号》形式给出，同目录下直接互链；跨目录用相对路径。
