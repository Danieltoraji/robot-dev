## 介绍

啊，伟大的搭档！我将向你介绍这美妙(?)的仓库了！

目前我们关卡的解决方案在goodluck.py。goodluck_sim.py是一个模拟器，可以用于验证算法的正确性。

模拟器的使用方法、常量定义等，请见`introduction.md`第十章。简而言之，在goodluck中修改算法代码，并将核心部分复制到模拟器对应部位，即可一键启动模拟。

`introduction.md`中还介绍了决策算法的详细逻辑。简而言之，整体框架保持不变，仍然采用导航点驱动的策略。相比于原算法有了以下主要优化：

- 分离了转向点和站立点，先到达站立点，再到达转向点。
- 增设了避障算法，离墙太近时直接导航到安全区。对于可能让机器人进入危险区的动作予以排除。
- 增加了定位失败的struggle，尝试左右转头。
